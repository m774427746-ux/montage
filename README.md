# مونتاج — أدوات المصمم للمطبعة

موقع عربي فيه أدوات تصميم وطباعة:

- **قوالب الأكواب**: ثمانية مقاسات من 4oz إلى 24oz، مع معاينة وتخصيص قالب الفرد وتنزيله SVG بأبعاده الفعلية.
- **حاسبة الأفرخ**: كم قطعة تطلع من الفرخ، وعدد الأفرخ والتكلفة، ومقارنة كل مقاسات الورق، وتنزيل المونتاج SVG.
- **حاسبة الاستيكرات**: العدد في المتر الطولي والمربع، وطول الطباعة والتكلفة، وتنزيل متر واحد SVG للقص.
- **حاسبة الأكريليك**: العدد في اللوح أو سرير الليزر، والوزن والتكلفة، وتنزيل ملف القص SVG.

الدخول بالبريد الإلكتروني فقط، بدون كلمة مرور.

## أدوات مصمم الأكريليك

قسم مستقل على `#acrylic-tools` يضم مولد لوح بفتحات تثبيت، لوحة باب، قاعدة بشق، شبكة فتحات، وميدالية. يدعم المقاسات بالمليمتر، زوايا دائرية، معاينة الأبعاد، SVG نظيف بالحجم الفعلي، وحفظ واستيراد إعدادات JSON. يتحقق من حدود الفتحات وتداخلها وأبعاد الشق.

السماكة وصف للخامة؛ في مولد القاعدة يُحسب عرض الشق من سماكة القطعة المركبة وسماحية الملاءمة. لا يُطبّق تعويض حرق الليزر. اختبر وصلة صغيرة واضبط التعويض في برنامج الماكينة.

التنفيذ في `src/acrylic-tools.html` ويُدمج أثناء البناء. للتحقق:

```bash
node src/build.mjs
node tests/acrylic-tools.mjs
```

## البنية

| المسار | الوصف |
|---|---|
| `public/` | الموقع بعد البناء (يُنشأ تلقائيًا في Vercel) |
| `src/admin.html` | لوحة المستخدمين على الرابط `/admin` |
| `api/signup.js` | يسجّل البريد عند الدخول ويحسب الزيارات |
| `api/stats.js` | يعرض المستخدمين لصاحب المفتاح `ADMIN_KEY` فقط |
| `src/app.html` | الأدوات |
| `src/gate.html` | شاشة الدخول بالبريد |
| `src/build.mjs` | يبني `public/` من ملفات `src/` |

## الإعداد على Vercel

1. استورد المستودع في Vercel. إعدادات البناء موجودة في `vercel.json`.
2. من تبويب **Storage** أضف قاعدة **Upstash for Redis** واربطها بالمشروع (تضيف `KV_REST_API_URL` و`KV_REST_API_TOKEN`).
3. أضف متغير البيئة `ADMIN_KEY` بقيمة سرية، ثم أعد النشر.
4. افتح `/admin` وأدخل المفتاح لرؤية عدد المستخدمين وتنزيلهم CSV.

## التعديل

عدّل `src/app.html` أو `src/gate.html` ثم شغّل:

```bash
node src/build.mjs
```
